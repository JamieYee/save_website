# 自定义图标包制作教程

通过导入符合规范的 `.zip` 压缩包，您可以轻松为【飞飞记账】添加专属的心仪图标。请务必按照下述规则构建您的压缩包。

## 1. 压缩包目录结构与规范

压缩包必须为 `.zip` 格式，并且**千万不能包含外层文件夹**（请全选相关文件与文件夹后直接打包压缩）。其内部结构必须如下：

```text
图标包.zip
├── 图标包名称.png       <-- 封面图片（必须在根目录的第一个文件）
├── config.json          <-- 排序配置文件（非必须，但推荐）
├── 支出/                <-- 图标分组 1（文件夹）
│   ├── 餐饮.png         <-- 具体图标文件
│   ├── 交通.png
│   └── 购物.png
└── 收入/                <-- 图标分组 2（文件夹）
    ├── 工资.png
    └── 兼职.png
```

### 规则详情
*   **封面图片**：放置在压缩包根目录下的图片文件（通常建议使用 `.png`）。系统会读取识别到的第一张图片作为该图标包的封面，且**该图片的名称（不带后缀）将直接作为系统内该图标包的名称**！
    *   *例如：若您希望新图标包叫做“可爱主题”，请在根目录放一张名为 `可爱主题.png` 的图片。*
*   **分组文件夹**：在根目录创建多个文件夹，每个文件夹代表一个图标**分组（Category Type）**。
    *   *例如：`支出`、`收入`，或者 `日常`、`娱乐` 等。系统只读取根目录下一级的文件夹，**请勿在文件夹内再嵌套子文件夹**。*
*   **具体图标文件**：将图标图片放置在对应的分组文件夹内。图片的名称（不带后缀）将作为您记账时看到的**图标名称**。
    *   *例如：`餐饮.png` 在使用时显示名称为“餐饮”。*
    *   *仅读取直接放置在分组文件夹内的文件文件。*
*   **绝对不能含有外层包裹文件夹**：请进入相关文件目录，按 `Ctrl+A` 或 `Cmd+A` 全选图片与文件夹后，使用右键菜单进行压缩。如果您的压缩包打开后看到的是一个“总文件夹”，点进总文件夹才是内容，**极高概率会导致系统无法读取任何图标，导致导入失败**。

## 2. 排序配置（可选：config.json）

如果您希望随意定义“分组的先后显示顺序”以及“分组内每个图标的前后顺序”，您可以在**压缩包根目录**放置一个 `config.json` 文件。

如果不提供此文件，系统将按照文件系统默认排序（通常为拼音或字母顺序）来随机展示。

### JSON 格式示例
`config.json` 文件内容应该是一个标准的 JSON 数据结构。键（Key）为分组文件夹的名称，对应的值（Value）为包含该分组内图标名称（不带后缀）的数组：

```json
{
  "支出": [
    "餐饮",
    "交通",
    "购物"
  ],
  "收入": [
    "工资",
    "兼职"
  ]
}
```

### 排序逻辑说明
1.  **分组排序大类**：APP 将严格按照 JSON 中大类“键”出现的先后顺序，对界面列表进行排序。在如上示例中，`支出` 会固定排在 `收入` 的前面。
2.  **图标排列顺序**：APP 将依照 JSON 数组中写入名称的前后顺序，对同一分页下的图标进行排序展示。在上述示例的 `支出` 分组中，将依次展示图标为 `餐饮` > `交通` > `购物`。
3.  **未配置项置底处理**：如果您向包中放入了某些新的图标文件或建立并命名了新分组，但忘记将其写入该 `config.json` 文件中，APP 依然会顺利读取并加载它们，但这些新项目由于缺少排序指令，会被APP自动排在**所有已配置项目的最后面**。

## 3. 注意事项与防坑指南

1. **封面缺省拦截**：系统在加载分析 ZIP 时核心操作是检查其根节点是否包含图文件。如果压缩包中不包含任何常规格式的图片，App将直接提示“未找到有效图片文件”，随后导入失败并终止工作。
2. **同名强制拦截**：如果被导入的图标包名称（由系统成功读取的第一张图片的名称决定）已经存在于应用中，系统安全判定将视其为防重复导入触发，主动跳过该次任务并提示“分类已存在”。
    - 若您重新制作修订了已经导入的图标包（比如加了个新图标）想更替使用，请**务必先进入 APP 删除对应的旧版本图标包**。
